# Upstream relationship

Jawa is an independent, downstream iteration of Rahul Kumar Mandal's
[`causalscreen`](https://github.com/rahulkm3/causalscreen) project. It is not
affiliated with, maintained by, sponsored by, or endorsed by the original author.

The initial design review used upstream commit
`ff3fb593a926df5f1db422e63a514d2591df245e` as its fixed reference. Jawa carries
forward the motivating questions—conditional feature screening, localized
structure, and possible drift—while independently redefining their statistical
contracts and engineering implementation. Upstream names and claims are not
evidence for Jawa's correctness.

The initial Jawa scaffold contains no copied `causalscreen` source code. The
upstream repository was distributed under the MIT License at the reviewed
revision. If future work copies or adapts upstream code, the contributing change
must identify the affected files and upstream revision and preserve all required
copyright and license notices. Conceptual attribution in this file does not
replace file-level license compliance.
